# Systematic Review & Meta-Analysis: ICD-11 Stroke Classification and Incidence

**Author:** Holli A. Groff, OD, MPH  
**Institution:** King's College London, MPH Epidemiology & Medical Analytics  
**Year:** 2023  
**Status:** Published 2024

## Overview
This repository contains the outputs from an independent systematic review and meta-analysis examining the impact of the new ICD-11 disease classification system on reported stroke incidence rates globally. This work was awarded the highest mark in the cohort and published in a peer-reviewed journal.

## Methods
- Structured literature searches across PubMed/MEDLINE, Embase, and Cochrane
- PRISMA-compliant screening and data extraction
- Meta-analytic modelling using R (meta and metafor packages)
- Critical appraisal using CASP and GRADE frameworks
- Heterogeneity assessment (I², Q-test, tau²)
- Sensitivity analyses and subgroup analyses

## Repository Contents
- Forest plots from meta-analytic analyses
- PRISMA flow diagram

## Publication
Groff H, et al. (2024). "A systematic review of the incidence and outcomes of ICD-11 defined stroke." *Journal of Stroke and Cerebrovascular Diseases*, Vol. 33, Issue 8, 107784.
